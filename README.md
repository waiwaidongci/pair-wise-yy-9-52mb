# 蓝晒冲洗水回用台

冲洗水回用管理：水缸登记、分用途冲洗、超时复检、底片用水履历。

## 运行

```bash
npm start
```

访问 `http://localhost:3040`。数据保存在 `data/rinse-water-reuse.json`。

## 业务规则

- 水缸登记来源、容量、银盐浓度、浊度与检测时间。
- 银盐浓度 > 0.5 mg/L、浊度 > 5 NTU 或检测超过 8 小时的缸只能待复检，不能冲洗。
- 冲洗按 预洗 / 显影后 / 定影后 选用途；同一缸同一时段（上午/下午/晚间）只接受一张底片，重复请求会指出占用底片且不写入用量。
- 复检须由检测人之外的另一人进行，连续两次合格才重新开放。
- 改检测或改用途会退回原使用许可，后续冲洗记录一并退回重算。

## 代码结构

- `src/rules.js` —— 规则：限值、缸状态判定、时段与复检规则
- `src/store.js` —— 存档：JSON 文件读写与种子数据
- `src/ops.js` —— 操作：建缸、登记冲洗、复检、改检测、改用途
- `server.js` —— HTTP 外壳与静态页面（`public/`）
